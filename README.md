# J&J Travel Adventures 🌏

A personal travel blog website created using **HTML and CSS**. This project showcases travel experiences, destinations visited, and photos from different trips.

## 📌 About the Project

J&J Travel Adventures is a travel blog website developed as part of a college web development project. It features individual travel pages where visitors can explore places we have visited, view travel photos, and read brief descriptions about each destination.

The website focuses on presenting travel experiences through a simple, organized, and user-friendly design.

## ✨ Features

- **Homepage** – Introduces the travel blog and provides navigation to individual travel pages.
- **Personal Travel Pages** – Separate sections for Jude's Travel and James' Travel.
- **Travel Destinations** – Displays places visited along with photos and short descriptions.
- **About Us** – Provides information about the people behind the travel blog.
- **Responsive Design** – Designed to provide a better browsing experience on desktop and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
